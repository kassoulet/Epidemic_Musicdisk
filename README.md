# Epidemic music disk (1994), in JavaScript

A browser port of **Epidemic**, the 1994 multi-group music disk by Renaissance / iCE (18 S3M tunes, DOS, 386+).
The program was reverse-engineered rather than re-imagined: graphics, fonts, palettes, texts, layout, fades,
particle field, button sprites and the rat mouse cursor all come from `EPIDEMIC.EXE` itself.
See [REVERSE.md](REVERSE.md) for how.

## Run

```
cd web
python3 -m http.server
# open http://localhost:8000 and click / press a key (browsers block audio until then)
```

No build step. Needs a browser with AudioWorklet (any current Chrome, Firefox, Safari).

## Controls (same as the original help screen)

| Key | Action |
|---|---|
| F1 | help (any key or click returns) |
| F2 / F3 / F4 | play / stop / pause |
| F5 / F6 (or arrows) | previous / next order |
| F7 / F8, `-` / `+` | previous / next song |
| 1-9, Q W E R T Y U I O | songs 1-18 |
| F10 / Esc | stop (original: exit to DOS) |
| Mouse | the seven icons under the screen behave as F2-F8; lower-right icon stops |

F9 (DOS shell) does nothing in a browser. Esc/Space/Enter skips the intro.

## What is original and what is not

| Part | Status |
|---|---|
| Player screen, help screen, intro pictures, fonts, palettes, texts, sprites | extracted from the EXE |
| Intro animation (ICE & REN scroll, gold zoom, bouncing head) | ported from the 32-bit code |
| Particle field, VU bar geometry and level rules, fade sequences, key map, hit boxes | ported from the 32-bit code |
| Audio | **not original**: libopenmpt (8-tap windowed sinc) instead of the Gravis Ultrasound engine |
| DOS shell, sound-card setup (`SETUP.EXE`), `EPIDNFO.EXE` | not ported |
| VU levels vs. audio sync | derived from pattern data at the row libopenmpt reports, so approximate in time |

## Layout

```
epidemic/   original release files (EXE, 3 song archives, NFO)
tools/
  unpack.py        runs the LZEXE-style stub under unicorn and dumps the unpacked image
  emu.py           emulator: DOS32 services, mode-X VGA, PIT, keyboard, GUS timer IRQ; screenshot/trace actions
  extract.py       builds web/assets from the EXE (images, palettes, glyphs, sprites, texts, particle table)
  browser-test.mjs headless-Chrome driver (keys, mouse, screenshot) used for testing
web/
  index.html       the whole UI (canvas 320x400, 70 Hz frame loop)
  s3m.js           minimal S3M reader (orders, instrument volumes, pattern events)
  vendor/          chiptune3 + libopenmpt (MIT / BSD), see vendor/LICENSE
  assets/ songs/   generated by tools/extract.py and by splitting the archives (see REVERSE.md)
```

## Regenerating the assets

```
pip install unicorn pillow
python3 tools/extract.py epidemic/EPIDEMIC.EXE web/assets
```

The 18 `.s3m` files in `web/songs/` are the modules found inside `EPIDEMIC.001/2/3` (each archive is a plain
concatenation; split at the `SCRM` signatures, title at offset 0).

## Debug URLs

`index.html?N#main` skips the intro and fast-forwards N frames; `#help` opens the help screen; `#intro` starts
the intro; `#main:+` presses a key after start. `tools/browser-test.mjs URL waitMs out.png [ms:key | ms:mm|md|mu:x:y]...`
takes a screenshot from real-time headless Chrome.
